# Read these commented copies first

This folder contains **documentation-only copies** of the project's backend and frontend files. Every original line is kept exactly as-is; a plain-English comment was inserted above it to explain what the line does and why it is there.

> **Do not edit these files.** They are for study only. Make all changes in the original files under `backend/` and `backend/static/`.

## How to study alongside `Spam_Detector_Documentation.pdf`

1. Open the PDF and keep it beside a commented file.
2. Find the matching section in the PDF, then read the commented file top to bottom.
3. Treat the inserted comments as a guided tour: the PDF explains the project as a whole, while the comments explain each individual line.
4. When you want to try a change, edit the **original** file and run the project again; these copies will not be updated automatically.

Comment syntax follows each file type: `#` for Python and requirements, `//` for JavaScript, `<!-- -->` for HTML and SVG, `/* */` for CSS, and `REM` for batch files.
